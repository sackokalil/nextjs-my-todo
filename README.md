# Next.js My Todo

A simple Todo application built while learning and practicing Next.js.

## About

This project was created as part of my Next.js learning journey.  
The goal was to build a small Todo application while practicing some of the core concepts of modern Next.js development.

## Features

- Create a new Todo
- Display Todos
- Edit existing Todos
- Delete Todos
- Store Todo data in MongoDB

## Concepts Practiced

During this project, I worked with:

- Next.js App Router
- Server Components
- Client Components
- Server Actions
- Route Handlers
- React hooks
- `useActionState`
- Form handling with `FormData`
- Data validation
- Data fetching
- Cache revalidation with `revalidatePath`
- Dynamic routes
- Prisma ORM
- MongoDB Atlas
- TypeScript

## Technologies

- Next.js
- React
- TypeScript
- Prisma
- MongoDB
- Tailwind CSS

## Purpose

This is a learning project rather than a production application. Its main purpose is to practice and better understand Next.js concepts by implementing them in a small CRUD application.
